# Logic_Analyzer-
Designing a Digital Logic Analyzer on a Basys 3 FPGA board using System Verilog, with 4 modular analyser blocks.  
Implemented real-time hardware decoding of SPI and I2C communication protocols, with configurable triggering on 
rising/falling edges. Integrated a MicroBlaze softcore processor for system control and using Arduino and I2C/SPI peripheral modules to generate test input signals for verification of the analyser blocks.
